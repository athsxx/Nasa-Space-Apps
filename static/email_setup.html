📧 Email Alert Setup Guide

Complete setup guide for Gmail API-based air quality email alerts

✅ Good News! SMS alerts have been upgraded to a more reliable Email alert system using Gmail API with beautiful HTML templates and enhanced security.

🚀 Step 1: Gmail API Setup

To enable email alerts, you need to set up Gmail API credentials:

  • Go to the Google Cloud Console
  • Create a new project or select existing one
  • Enable the Gmail API
  • Create credentials (OAuth 2.0 Client ID)
  • Download the credentials JSON file
⚠️ Important: Save the credentials file as gmail_credentials.json in the project root directory.

🔧 Step 2: Environment Setup

Install required Gmail API packages:

pip install google-auth google-auth-oauthlib google-auth-httplib2 google-api-python-client

These packages are already included in your current environment.

🎯 Step 3: OAuth Authentication

First time setup requires OAuth authentication:

  • Run the server and make your first email API request
  • A browser window will open for Gmail authorization
  • Sign in with your Gmail account
  • Grant permission to send emails
  • The token will be saved automatically for future use
🔒 Security Note: The system uses OAuth2 with secure token storage. Your Gmail password is never stored or accessed.

📱 Step 4: Using Email Alerts

Available email alert endpoints:

# Subscribe to email alerts GET /email/subscribe?email=user@example.com&location=New York&threshold=100 # Unsubscribe from alerts GET /email/unsubscribe?email=user@example.com # Send test email GET /email/test?email=user@example.com # Check service status GET /email/status # View this setup guide GET /email/setup

🚨 Migration from SMS

If you were using SMS alerts before:

  • SMS endpoints now return deprecation warnings
  • All SMS functionality redirects to email alternatives
  • Your existing alert preferences need to be recreated for email
  • Email alerts are more reliable and feature-rich than SMS
📈 Upgrade Benefits: Email alerts support HTML formatting, images, better deliverability, and detailed AQI visualizations that SMS couldn't provide.

🛠️ Troubleshooting

Common issues and solutions:

  • Credentials Error: Ensure gmail_credentials.json is in the correct location
  • Authentication Failed: Delete token.json and re-authenticate
  • Permission Denied: Check Gmail API is enabled in Google Cloud Console
  • Rate Limits: Gmail API has daily sending limits for free accounts
