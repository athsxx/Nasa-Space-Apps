🤖 Telegram AQI Alert Bot Setup

⚠️ Important Note About Chat IDs

The Chat ID 8348450996 is the Bot's own ID, not a user Chat ID!

Bots cannot send messages to themselves. You must use your personal Chat ID to receive messages.

🎯 Goal: Get air quality alerts directly in your Telegram chat! Fast, reliable, and completely free notifications.

Step 1: Start the Bot

  1. Click this link to open the bot: @YourAQIBot
  2. Click "Start" or send /start
  3. The bot will respond with a welcome message

Step 2: Find Your Chat ID

🔍 Easy Chat ID Finder:

  1. Forward any message to: @userinfobot
  2. It will reply with your Chat ID (looks like: 123456789)
  3. Copy this number - you'll need it to subscribe

Alternative: Send /chatid to our bot and it will show your Chat ID

Step 3: Subscribe to Alerts

Use this API endpoint to subscribe:

GET /telegram/subscribe?chat_id=YOUR_CHAT_ID&location=New York&threshold=100

Parameters:

  • chat_id: Your Telegram Chat ID (from Step 2)
  • location: City or location to monitor
  • threshold: AQI level to trigger alerts (default: 100)

Example:

http://localhost:8080/telegram/subscribe?chat_id=123456789&location=Los Angeles&threshold=85

Step 4: Test Your Setup

Send a test alert to verify everything works:

GET /telegram/test?chat_id=YOUR_CHAT_ID

Example:

http://localhost:8080/telegram/test?chat_id=123456789

You should receive a test AQI alert in your Telegram chat!

🔧 Available Commands

API Endpoints:

  • Subscribe: /telegram/subscribe?chat_id=123&location=City&threshold=100
  • Unsubscribe: /telegram/unsubscribe?chat_id=123
  • Test Alert: /telegram/test?chat_id=123
  • Bot Status: /telegram/status

Bot Commands (in Telegram chat):

  • /start - Start interaction with bot
  • /help - Show help message
  • /chatid - Get your Chat ID
  • /unsubscribe - Unsubscribe from alerts
