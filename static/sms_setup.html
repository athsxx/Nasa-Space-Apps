🔧 Setup Steps Required

📱Step 1: Get a Twilio Phone Number

You need a phone number to send SMS from. For trial accounts, you can get a free number:

  1. Go to Twilio Console
  2. Navigate to Phone Numbers → Manage → Buy a number
  3. Choose any available number (free for trial accounts)
  4. Configure the number for SMS

✅Step 2: Verify Recipient Phone Numbers

Trial accounts can only send SMS to verified numbers:

  1. Go to Twilio Console
  2. Navigate to Phone Numbers → Verified Caller IDs
  3. Add your phone number and complete verification
  4. You can add multiple numbers for testing

🔄Step 3: Restart the Service

After completing the above steps:

  1. Restart the NASA server
  2. The system will automatically detect your new phone number
  3. Test SMS functionality with verified numbers

🧪 Testing Instructions

Once setup is complete:

  1. Go to the SMS Alerts tab in the main application
  2. Enter a verified phone number (from Step 2)
  3. Enter your location (e.g., "Los Angeles, CA")
  4. Click Subscribe to SMS Alerts
  5. You should receive a welcome SMS immediately

🆘 Troubleshooting

Common Issues & Solutions

  • "Not a verified number": Add the recipient number to Verified Caller IDs
  • "No phone number available": Get a Twilio phone number from the console
  • "Premium rate number": Don't use test numbers, use real mobile numbers
  • "Account not authorized": Complete phone number verification
💡 Pro Tip: Once you upgrade from trial to paid account, you can send SMS to any valid phone number without verification.
